1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Quizreto is a full-stack, responsive assessment platform designed to deliver
engaging, culturally resonant quizzes with real-time scoring, analytical
dashboards, and user-driven quiz creation.

During this milestone, the application underwent complete production-grade
engineering:
  1. Full containerization of the Python FastAPI backend and React/Vite frontend.
  2. Multi-tier Docker Compose orchestration with PostgreSQL 16.
  3. Cloud PostgreSQL database provisioning and migration on Supabase.
  4. Serverless cloud deployment of both frontend and backend on Vercel under
     a unified project domain.
  5. Built-in database seeding providing 5 comprehensive starter quizzes with
     25 verified questions across History, Science, Technology, Geography,
     and Literature.
  6. Transition from static question metadata to real-time dynamic question
     counting across all API endpoints and frontend cards.
  7. Comprehensive architectural documentation and setup guides.

2. TECHNICAL ARCHITECTURE & STACK
--------------------------------------------------------------------------------
Frontend:
  - Framework: React 19 with TypeScript
  - Build Tool: Vite 8.3
  - Styling: Tailwind CSS v4 with bespoke Indian aesthetic palette
  - Routing: React Router v7 (SPA with client-side history)
  - Icons & FX: Lucide React, Canvas Confetti
  - Networking: Axios with authorization bearer interceptor and response handlers

Backend:
  - Framework: FastAPI (Python 3.11 / 3.12 ASGI)
  - Server: Uvicorn (standard worker)
  - Database ORM: SQLAlchemy 2.0 with DeclarativeBase
  - Migration Manager: Alembic
  - Security: Passlib (Argon2id hashing), Python-Jose (JWT HS256 tokens)
  - Data Validation: Pydantic v2 schemas

Infrastructure & Storage:
  - Cloud Database: Supabase Cloud PostgreSQL 17 (Session Pooler with TLS)
  - Local Containers: Docker multi-stage builds (Alpine Linux, Python slim)
  - Orchestration: Docker Compose (db, backend, frontend)
  - Cloud Hosting: Vercel Services (Unified Vite + FastAPI Serverless Monorepo)

4. KEY ENGINEERING CHALLENGES & RESOLUTIONS
--------------------------------------------------------------------------------
1. Empty Initial Alembic Migration:
   - Challenge: The generated migration c0467716232e_create_users_table.py contained
     an empty pass statement, causing foreign key failures when quizzes table was created.
   - Solution: Handcrafted proper Table and Column definitions with indexes for
     email and primary key, restoring migration integrity across all environments.

2. Vercel Serverless IPv6 Incompatibility with Direct Supabase Host:
   - Challenge: Supabase direct connection host (db.<project>.supabase.co) only
     resolves to an IPv6 address (AAAA record). AWS Lambda / Vercel serverless
     functions run on IPv4-only networks, resulting in 500 Connection Timeouts.
   - Solution: Migrated connection URI to Supabase's Session Pooler
     (aws-0-ap-south-1.pooler.supabase.com:5432) with username format
     postgres.<project_ref> and sslmode=require. Implemented automated fallback
     regex translation in backend/app/database.py to ensure zero downtime.

3. Port Collision on Local Host during Docker Testing:
   - Challenge: Local port 8000 was held by an external container.
   - Solution: Configured BACKEND_PORT in docker-compose.yml to default to 8001
     for host mapping while preserving internal port 8000 on the bridge network.
